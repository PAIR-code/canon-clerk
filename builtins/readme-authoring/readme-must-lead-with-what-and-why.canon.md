The repository `README.md` MUST lead with a concise statement of the project's core purpose ("what") and value proposition or problem space ("why").

Precedent: Inverted Pyramid principle; Diátaxis documentation framework.

Rationale: Visitors and AI coding assistants rely on the opening lines of landing documentation for rapid orientation; burying the project's purpose beneath installation commands, badge walls, or implementation details impairs comprehension and causes high cognitive bounce rates.
