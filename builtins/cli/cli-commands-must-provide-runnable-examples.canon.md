CLI command help screens (`--help`) MUST include at least one realistic, copy-pasteable runnable usage example demonstrating common flag configurations alongside argument definitions.

Precedent: GNU Coding Standards §4.8; Command Line Interface Guidelines (clig.dev §Help).

Rationale: Concrete examples communicate workflow invocation context and argument combinations that isolated, abstract flag lists cannot convey.
